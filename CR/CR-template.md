## 如何使用本範本

1. **每個變更案例填寫一份**。例如 POC 內有「2 個真實變更案例」，便各填一份，並使用不同識別碼。
2. 標示 `【必填】` 的欄位須在提交前完成；標示 `【選填】` 的欄位如暫時未能確定，可填「待確認」。
3. 每個欄位下方的 `> 填寫說明` 為指引，`> 範例` 為參考內容。**正式提交前請刪除所有說明及範例文字**。
4. 勾選方式：`[x]` 代表是／已確認，`[ ]` 代表否／未確認。
5. 第 6 節（技術需求）及附錄 A（程式碼交付清單）是**日後接收程式碼能否無縫銜接**的關鍵，請盡量填妥。
6. 如有任何欄位不理解，請聯絡 Bob／PPZ 團隊窗口（見第 5 節）。

> **語法提示**：此為 Markdown 檔案，可使用任何文字編輯器、VS Code 或 Bob IDE 直接編輯；亦可用 Pandoc 等工具轉換為 Word（`pandoc 本檔.md -o 本檔.docx`）。
